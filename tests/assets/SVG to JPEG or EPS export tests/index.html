ICONSPLITTER / LOCAL FILE CHECK

Does the metadata travel with the file?

Upload an exported JPEG or EPS to inspect its embedded title, description and tags.

No account. No server upload. No sidecar.

Files stay in your browser. This independent reader uses only the selected file's bytes; it never consults IconSplitter, export.json or a metadata cache. EPS programs are never executed.

  1. Export with accepted metadata and EPS enabled in SVG to upload.
  2. Select the exported .jpg and .eps below (multiple files allowed).
  3. Confirm Title, Description and Tags match. Open the IPTC compatibility copy to check legacy readers too.

50 MB per file. Full fields use XMP; legacy IPTC copies have format byte limits. Each stock website decides which metadata it imports; this is a file-readback test, not a guarantee for every site.

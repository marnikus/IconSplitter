# SVG builder — text placement, templates and preset JSON (2026-11-13)

Parent: [SVG builder](svg-builder.md) · [selectors](../selectors/svg-builder.md) · [storage](storage/svg-builder.md) · [tests](tests/svg-builder.md).

- **Text placement** (2026-11-13): *Text padding* 0–120 px insets the banner text from its edge (the painted block stays); *Move title / Move subtitle* X/Y −400…400 px (typed, arrow keys step 1); ↺ resets. Part of the look, so templates keep it. **Double-click** the title or subtitle on the artboard to edit it in place: Enter or clicking outside saves (one undo entry), Escape cancels, Shift+Enter = new line (`SvgBuilderInlineText.tsx`, native listener: the SVG is in a shadow root; text blocks carry `data-banner-text`).
- **Saved templates** (2026-11-13, `lib/svgBuilder/templates.ts`, `actions/templates.ts`): ＋ Save template keeps the sheet's **look** — artboard, grid, icon style, banner and text style; never the banner title/subtitle or hero (`lookOf`) — as a compact block with a generated name ("Side banner · 8×4 · Split", numbered when taken; renamed in place). The block's picture is that look on the current sheet with its loaded icons (dashed cells without one). Clicking it (or ✎) opens it on the sheet — one undo entry, the sheet's words and hero kept — and marks it *editing*: ✓ Save template writes the look back, *Save as new* copies it, *Done editing* stops. ✕ removes it at once. At most 60. A **PREVIEW** zoom (the shared 48–800 px slider) sets the pictures' height at each template's own aspect; remembered in prefs.
- **Preset JSON** (2026-11-13, `lib/svgBuilder/presetjson.ts`, header `{ } Preset JSON` / Export ▾): the whole sheet as editable JSON (`format` iconsplitter-sheet-preset v2: config incl. text placement, `icons` by Icon Name → title → file stem → id, `null` = empty cell, `lockedIcons`, seed, recipe, metadata). Apply merges onto the sheet (omitted fields keep their value; ranges clamp); names not found stay empty and are reported, never guessed; the rest of the grid stays empty. *Copy for AI* = parameter guide + JSON + all Icon Names. Save/Load preset use the same JSON; older id presets still load.
- **Icon map** (`lib/svgBuilder/iconmap.ts`, `iconmapstore.ts`): after every scan `icon-map.json` is (re)written in the **scanned root** (only when its content changed): `format` iconsplitter-icon-map v1, `root`, `count`, and per icon WITH an Icon Name: `name`, `id`, `title`, `folder` (relative), `folderPath` (full, when the root path is known), `files` {`svg`, `svgJson`, `preview` (the pair's AI image), `exportJson`, `index`, `usage`}. Sorted by name, then id (code-point order). The folder bar shows its full path (`builder-icon-map`, Copy path) — the clue for an AI to find an icon's folder by name or id.
- **Final artboards** (`lib/svgBuilder/artboards.ts`, `actions/artboards.ts`, `artboardmeta.ts`, `SvgBuilderArtboards.tsx`): a template is the blueprint (look + grid; no words, no icons). Templates are checkable blocks with RULE 25 gestures (picture click activates, checkbox/Ctrl/Shift check, ✎ edits the design). **＋ Artboard** adds a final artboard (generated name "<template> — #N", id `art-…`) and opens it EMPTY on the stage: pick icons in the library or Reshuffle; title, subtitle, hero, icons, locks and sheet metadata are written back while it is open (`useArtboardSync`; the first render after opening is skipped so the previous sheet is never copied in). It always draws with its template's current look. The list under the templates shows the artboards of the CHECKED templates (else the active one), grouped by template, with the same gestures (plain click activates = opens on the stage, Up/Down, E/Q, header tri-state) and a bulk bar: ✦ Generate metadata (one confirmation showing every exact 768 px JPEG + prompt; one request per artboard, no retry; valid → accepted on that artboard) and ✕ Remove. Removing a template removes its artboards. Opening an artboard adds no undo entry.
- **Icon use** (`lib/svgBuilder/usage.ts`, `usagestore.ts`, `actions/usage.ts`): `<svg>.usage.json` beside each approved SVG, next to its `.index.json`: `used` (exported artboards that held the icon), `last`, `history` (newest first, ≤ 50: when, which artboard). Read with the scan. An SVG/PNG export (not a clipboard copy) saves one more use per icon for good: an open artboard counts each icon once (`countedIds`; re-export does not count again, an icon added later counts at the next export); a plain sheet counts once per session for the same icons and look. Icons on artboards whose use is not saved yet are **pending** (`pendingUse`; removing an icon takes it off). Every library tile shows `×N` (+M pending), also `×0`; every icon on the artboard shows the same index bottom-left (`builder-cell-use-<cell>`), switched by **# Used** in the stage toolbar (prefs `showUsage`, default on); tooltips spell it out.

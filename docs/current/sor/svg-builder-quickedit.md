# SVG builder — quick edit

Parent: [templates & presets](svg-builder-presets.md) · selectors: [templates & artboards selectors](../selectors/svg-builder-presets.md).

- **Quick edit on the artboard** (2026-11-14, `quickedit.ts`, `SvgBuilderQuickEdit.tsx`, `lib/svgBuilder/swatches.ts`): hovering an element shows a small toolbar beside it (outside the scaled artboard, so zoom-independent): grid icon → ● colour + ≡ stroke; banner icon → ● accent + ≡ icon stroke + ◯ circle (stroke, size) + ⤢ size (icon + circle together keeping their ratio, icon, circle); title → ● colour + **A** (font list + size); subtitle → ● colour + **A** (size); banner / split block / background → ● colour. The colour panel: six smart swatches near the current colour (lighter, darker, muted, richer, neighbouring hues), a custom picker (gradient dot) and a hex field + Done. Every change is one `setConfig` (sliders and the picker coalesce into one undo gesture). Targets come from the native event path (`data-banner-text`, `data-banner-hero`, `data-split-block`, `data-banner`, `data-artboard`, `.bld-cell`); the toolbar has ONE place per element, from the layout, never the pointer (`quickplace.ts` `anchorOf`, `lib/svgBuilder/freespot.ts`): always INSIDE its own element and clear of every other element, so the pointer never crosses another element on its way (inside corners first, then a scan): background → free background (not the banner, icon cells with captions); banner → not its texts, icon or split block; split block → not the texts/icon on it; icon → inside its cell, clear of ×, 🗑, ○; text / banner icon → inside its box; too small → the element's own top edge. It moves only when the layout or text moves, and NEVER while a panel is open: it stays where it opened until the panel closes (`usePinnedAnchor`), so editing a value that resizes the element does not make the toolbar jump away mid-edit. It hides 0.4 s after the pointer leaves, never while a panel is open (that bug left an open panel with no toolbar and stopped hovering for good). Title/subtitle get **✥ Move**: a dashed frame with left/right handles (X), top/bottom handles (Y), the text body (both), arrows nudge 1 px / Shift 10 px; a red guide and an "X +12 px" badge; every move applies at once (one coalesced undo gesture), Apply closes (`SvgBuilderTextMove.tsx`). Builder number boxes apply as you type when the value is in range; out-of-range values wait for blur/Enter, then clamp, stays while a panel is open; outside click or Escape closes.

# SVG builder — quick edit

Parent: [templates & presets](svg-builder-presets.md) · selectors: [templates & artboards selectors](../selectors/svg-builder-presets.md).

- **Quick edit on the artboard** (2026-11-14, `quickedit.ts`, `SvgBuilderQuickEdit.tsx`, `lib/svgBuilder/swatches.ts`): hovering an element shows a small toolbar beside it (outside the scaled artboard, so zoom-independent): grid icon → ● colour + ≡ stroke; banner icon → ● accent + ≡ icon stroke + ◯ circle (stroke, size) + ⤢ size (icon + circle together keeping their ratio, icon, circle); title → ● colour + **A** (font list + size); subtitle → ● colour + **A** (size); banner / split block / background → ● colour. The colour panel: six smart swatches near the current colour (lighter, darker, muted, richer, neighbouring hues), a custom picker (gradient dot) and a hex field + Done. Every change is one `setConfig` (sliders and the picker coalesce into one undo gesture). Targets come from the native event path (`data-banner-text`, `data-banner-hero`, `data-split-block`, `data-banner`, `data-artboard`, `.bld-cell`); the toolbar has ONE place per element, from the layout, never the pointer (`quickplace.ts` `anchorOf`, `lib/svgBuilder/freespot.ts`): always INSIDE its own element and clear of every other element, so the pointer never crosses another element on its way (inside corners first, then a scan): background → free background (not the banner, icon cells with captions); banner → not its texts, icon or split block; split block → not the texts/icon on it; icon → inside its cell, clear of ×, 🗑, ○; text / banner icon → inside its box; too small → the element's own top edge. It moves only when the layout or text moves, and NEVER while a panel is open: it stays where it opened until the panel closes (`usePinnedAnchor`), so editing a value that resizes the element does not make the toolbar jump away mid-edit. It hides 0.4 s after the pointer leaves, never while a panel is open (that bug left an open panel with no toolbar and stopped hovering for good). Title/subtitle get **✥ Move**: a dashed frame with left/right handles (X), top/bottom handles (Y), the text body (both), arrows nudge 1 px / Shift 10 px; a red guide and an "X +12 px" badge; every move applies at once (one coalesced undo gesture), Apply closes (`SvgBuilderTextMove.tsx`). Builder number boxes apply as you type when the value is in range; out-of-range values wait for blur/Enter, then clamp, stays while a panel is open; outside click or Escape closes.

- **Banner icon hover area** (2026-11-14, `herohit.ts`): SVG only reacts on painted lines, so the preview adds one invisible box (`data-hero-hit`, `fill="none"` + `pointer-events="all"`, 4 px around the icon + circle bounds) as the first child of every `[data-banner-hero]` after each redraw. The whole icon + circle area then opens the toolbar, like a grid icon cell. Preview only: exported SVGs never contain it.
- **Edge grips** (2026-11-14, `lib/svgBuilder/edgedrag.ts`, `SvgBuilderEdgeHandles.tsx`): while the pointer is on the artboard, purple grips appear on the banner's inner edge (drag = Banner width/height, clamped to its range) and on the middle of each icon-area padding edge except the side touching the banner (drag inward = more padding, 0–160 px). Screen-sized at any zoom, a live value badge while dragging; each drag is exactly one undo step (its own history `gesture` id, so quick successive drags never merge). Preview only.
- **Artboard size grips** (2026-11-14, `artboardSizeAfter`): teal grips just OUTSIDE the artboard (12 px; `SvgBuilderSizeHandles.tsx` on the unscaled wrap, since the artboard clips its overflow): right of the right edge (width), below the bottom edge (height) and off the bottom-right corner (both); shown while the pointer is on the artboard or its 26 px margin, clamped to 320–3000 × 240–3000; the badge shows "W × H"; one undo step per drag. The artboard grows from its top-left, so there are no left/top size grips. In Fit zoom the stage refits while dragging.
- **Gap strips** (2026-11-14, `lib/svgBuilder/gapdrag.ts`, `SvgBuilderGapHandles.tsx`, shared `trackdrag.ts`): only while ▦ Guides is on. Every gap between two neighbouring icons is an invisible strip (at least 12 px, so a zero gap can be caught); near it a grip shows ("‖" Gap X between columns, "=" Gap Y between rows) and the strip highlights. Dragging it changes that gap (the grid's auto-fit is undone, so the gap follows the pointer), 0–200 px, live badge, one undo step per drag.
- **Captions** (2026-11-14): every caption is marked `<g data-caption="<cell>">`; hovering one shows ● Caption colour + **A** Caption size (`grid.captionColor`, `grid.captionSize` 5–100, plus **Gap to icon** `grid.captionGap` 0–120 px — the sheet-wide caption style, so all captions change; the gap also sits in Customize and makes the caption row taller). Its toolbar sits just under the caption, overlapping its lower edge (a caption is narrower than the toolbar). **Double-click a caption** to type its own words (Enter / click outside saves, one undo step; Escape cancels): they are kept in `banner.captionTexts` (icon id → words) of THIS template or artboard only — like its title: the icon's metadata never changes, a template keeps its own typed captions as samples, an artboard keeps its own and never takes the template's. Typed words show exactly as typed (no caption case); emptying a caption shows the icon's name again.
- **Title / subtitle width** (2026-11-14, `SvgBuilderTextWidth.tsx`, `banner.titleWidth` / `subtitleWidth`, 0–2000 px, 0 = automatic): hovering the title or subtitle also shows a grip at its right edge (`builder-text-width-title` / `-subtitle`). Dragging it sets that text's box width: the text wraps by width instead of the reference character limits (25 / 28 characters on edge banners). Centred side-banner text grows on both sides, so the drag counts twice. Minimum 40 px; live badge; one undo step per drag; the toolbar stays while dragging. The double-click editor opens at least that wide and can be widened by hand; a widened editor keeps its width as the text width when it saves.
- **⇔ Rebalance row** (2026-11-15, `lib/svgBuilder/rebalance.ts`, `banner.edgeSpread`; Customize → Banner → text placement, for top/bottom banners — solid, and since 2026-11-15 split (the hero + title evenly inside the accent block, the subtitle centred in the rest) — `builder-banner-rebalance`): one undo step that sets each text's width to its own one line, clears Text padding and the title/subtitle moves, and turns on the spread layout (`banner.ts` `edgeXs`). The row's present parts (hero glyph, title, divider as a zero-width part, subtitle) get EQUAL gaps between each other and both banner edges; the subtitle is no longer capped at 380 px there. **Centred row** (`builder-banner-rebalance-off`) returns to the reference centred group with fixed gaps.
- **✎ Edit icon** (2026-11-15, `SvgBuilderIconEditor.tsx`, `iconedit.ts`): the icon's quick bar has ✎ (`builder-quick-edit-icon`). It opens the Generate SVG tab's full-screen editor (`SvgPathEditor` + the AI source panel showing `<stem>.png`) on that icon's SVG in the builder's folder. **Finish** writes it with Generate SVG's writer as one undo step (history type `builderSvgEdit`, routed in `state/apply.ts`); the sheet and the library redraw at once. ← / → step through the icons placed on the artboard (saving first when asked). Cancel drops the session.
- **Text case and size** (2026-11-15, `banner.titleCase` / `subtitleCase`, `applyCase`): the title and the subtitle each read **normal / Capitalized / UPPER**. The default keeps the old look: title as typed, subtitle upper. They are set in Customize → Banner (`builder-title-case`, `builder-subtitle-case`) and in the text's quick **A** panel (`builder-quick-case-{normal,capitalized,upper}`). The title and subtitle sizes go up to 200 px.
- **Icon box** (2026-11-15): the icon's quick bar also has **⬚** (`builder-quick-box`). It opens the Icon box slider (`icons.box`, 18–240 px, `builder-quick-box-range`): the size every icon cell uses, so all icons change; one coalesced undo step.
- **Auto rebalance** (2026-11-15, `banner.autoRebalance`): a checkbox beside ⇔ Rebalance row (`builder-banner-auto-rebalance`). Also in the banner's quick bar: **⇔** (`builder-quick-rebalance`) with **Rebalance now** and **Auto rebalance** (`builder-quick-rebalance-now` / `-auto`). While on, `bannerMarkup` applies the rebalance on every draw, for the texts and sizes as they are then, so editing them never breaks the balance; stored widths and moves are ignored meanwhile. Turning it on also applies the rebalance once (one undo step).
- **Rebalance rules** (2026-11-15, replacing the per-part spread on solid edge banners; `rebalance.ts` `fitRow`, `banner.ts` `spreadEdge`):
  1. Title and subtitle each on one line.
  2. Three equal gaps: edge → title → subtitle → edge. Without a subtitle, the title is centred between two equal gaps.
  3. Texts too long: both sizes shrink by the same factor until every gap is at least 5 % of the row (`ROW_MIN_GAP`), and the middle gap also holds the hero. The button writes the fitted sizes (rounded down); drawing fits again whenever the texts change.
  4. The hero glyph, else the divider, sits exactly in the middle of the gap between the texts and follows automatically.

  Split edge banners keep the block layout (hero + title evenly in the block, the subtitle centred in the rest).

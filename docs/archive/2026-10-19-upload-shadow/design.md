# Upload artboard shadow — implementation plan (2026-10-19)

The Upload tab already previews `prepareExportSvg` and exports that same prepared SVG. The existing `src/svg/templates/shadow.svg` is a 204×24 radial-gradient ellipse, but it is not part of the artwork. Checked icons must receive an optional shadow centred below their final painted icon, not a preview-only CSS effect. The approved source remains unchanged.

1. Write failing settings, geometry, preview/export, selected-only UI and undo tests first. Shadow is off by default; legacy exports and the default fingerprint remain byte-for-byte unchanged.
2. Add validated per-icon shadow enable, width (80% default; 10–200%) and bottom gap (5% default; 0–100%). A checked-only Shadow **checkbox in the global Export settings popup** enables or removes the effect as one undoable settings action; selected width/gap controls there adjust only already-shadowed checked icons, never an off or active-but-unchecked row. Global numeric defaults in a separate block never opt unchecked icons in. Per-icon settings remain editable. A separate bulk Apply settings action must preserve existing shadow pins.
3. Bundle the existing SVG template as raw text. Extract its ellipse/stops/opacity, convert its ellipse-aligned radial gradient to visually identical `objectBoundingBox` coordinates, and assign a collision-free ID. Insert after the icon's bake/restyle/stroke expansion so measurements use shipped painted bounds; draw it behind the icon and after the artboard background. Fit the union into content/source/pinned/megapixel artboards; with null padding retain the source viewBox as an unpainted frame, extending it only for overflow. No filters or raster shapes in the exported SVG.
4. Reuse `prepareExportSvg` for both preview and export. Append the template hash and full validated width/gap to the settings fingerprint only when shadow is enabled so changed templates and parameters make existing packages stale. Built-in EPS cannot draw gradient paint: warn in the UI and let that stage report partial while SVG/JPEG commit; detach any previous EPS from the new partial record without deleting old bytes, leaving the optional local Inkscape choice untouched. Refuse Shadow when extending a source frame would reveal clipped art; capture width/height-only frames before cleanup and ignore fully transparent or hidden geometry in painted bounds, including hidden expanded stroke outlines. An outline uses the effective stroke opacity rather than inheriting an unrelated fill opacity.
5. Update the owning Upload settings/geometry/export/EPS/selector/test/invariant documentation and append a measured entry to the quality ledger without reading it. Finish with focused red→green tests, typecheck, lint, quality gate, fast/full verification, staged-diff review and a scoped commit/push.

No live provider calls, external SVG requests or source-file edits are part of this feature.
